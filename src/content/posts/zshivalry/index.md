Ever wanted to reminisce back to the medieval days while using your terminal? Sometimes feel like shell commands are too short and hard to remember? Miss that tavern vibe while checking for any brew upgrades?

Look no further.

With zshivalry you get to navigate and use your terminal like a true poet. Need super user permissions to perform a command, try `by mine authority`. Want to grep something, try `seeketh`. If you feel like navigation is a bit too effortless, try `pilgrimage` or `venture` to change directories. You can always `retreat` or even `homecastle` if you travel too far.

## Examples

`sudo ls /var/sys/logs | grep 'error'` -> `by mine authority hark /var/sys/logs | seeketh 'error'`

🔗 [Check out the full terminology here](https://github.com/NikolaiDokken/devtools/blob/main/dotfiles/.zshivalry.zsh)
